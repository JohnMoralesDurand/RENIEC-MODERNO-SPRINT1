> Como usuario, quiero recuperar mi contraseña mediante un enlace enviado a mi correo, para volver a ingresar si la olvido.

## Criterios de aceptación

- **Éxito:** Dado un correo registrado, cuando solicita recuperar la contraseña, entonces recibe un enlace válido por 60 minutos y puede definir una nueva.
- **Error:** Dado un enlace vencido o ya usado, cuando intenta usarlo, entonces se rechaza y se ofrece pedir otro; si el correo no existe, el mensaje es genérico.
